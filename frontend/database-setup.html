MySQL Connection Issue

The application cannot connect to a database. This is normal on first deployment or when running in production without proper database setup.

Your Loyola Admissions System is ready to use! To get started, choose one of the options below based on your deployment environment.

📋 Option 1: Local Development (Recommended for Testing)

If you're running this locally on your computer:

1
Install MySQL locally

Download and install MySQL Community Server. During installation, set root password to: Baba@1531

2
Verify MySQL is running
net start MySQL80
3
Restart the backend server
python main.py

Or if using uvicorn:

uvicorn main:app --host 127.0.0.1 --port 8002

☁️ Option 2: Vercel / Cloud Deployment (Production)

For production deployment on Vercel or similar platforms, use a cloud database like Supabase:

1
Sign up for Supabase

Create a free account at supabase.com and create a new PostgreSQL database project.

2
Get database credentials

From Supabase dashboard, copy your connection string or credentials (host, user, password, database name).

3
Set Vercel environment variables

In Vercel dashboard → Settings → Environment Variables, add:

MYSQL_HOST=your-supabase-host
MYSQL_USER=postgres
MYSQL_PASSWORD=your-password
MYSQL_DB=postgres
4
Redeploy on Vercel

Push your code to GitHub, and Vercel will automatically redeploy with the new environment variables.

❓ Need Help?

Common Issues:

  • MySQL already running locally? The app will auto-connect once MySQL is confirmed to be running.
  • On Vercel but still disconnected? Make sure environment variables are set correctly and redeploy.
  • PostgreSQL instead of MySQL? Contact support to upgrade the backend driver for PostgreSQL.
